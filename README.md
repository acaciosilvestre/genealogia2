# Genealogia2

Sistema/projeto para organização e visualização de dados genealógicos.

## 📋 Sobre o projeto

O **Genealogia2** foi criado para armazenar, consultar e organizar informações familiares e árvores genealógicas de forma simples e estruturada.

## 🚀 Funcionalidades

* Cadastro de pessoas
* Relacionamentos familiares
* Visualização de árvore genealógica
* Pesquisa de familiares
* Organização de dados históricos

## 🛠️ Tecnologias utilizadas

Adicione aqui as tecnologias do projeto, por exemplo:

* HTML
* CSS
* JavaScript
* Python
* Node.js
* Banco de dados SQLite/MySQL/PostgreSQL

## 📦 Instalação

Clone o repositório:

```bash
git clone https://github.com/acaciosilvestre/genealogia2.git
```

Entre na pasta:

```bash
cd genealogia2
```

Instale as dependências (se houver):

```bash
npm install
```

ou

```bash
pip install -r requirements.txt
```

## ▶️ Como executar

Exemplo:

```bash
npm start
```

ou

```bash
python app.py
```
